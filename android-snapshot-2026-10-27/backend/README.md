# Portafoglio Petali (candidato, non distribuito)
Questo modulo è dedicato esclusivamente a Petali. NON eseguire il file SQL sui progetti SimulaEsame, Gatto Giudice o SofiaApp.

* Account autenticati via email OTP verificata. L'attuale form Petali salva solo email e consenso localmente; non è autenticazione. Serve un progetto Supabase dedicato, configurazione del provider email/OTP, SMTP di produzione e protezione anti-abuso. Il progetto gratuito esistente ha già due database e nessuno è Petali. La connessione Cloudflare corrente non dispone delle autorizzazioni D1/Workers.
* Saldi modificati solo da transazioni server. +100 benvenuto e +10 il primo giorno, +10 al giorno successivo, +100 extra ogni decimo giorno consecutivo (UTC), reset se si salta il giorno. Codice personale PET- univoco. Invito registrato una sola volta entro 24 ore dalla creazione e dopo verifica email. Primo, secondo, terzo amico: +50, +50, +100 (totali 50, 100, 200). Ulteriori amici registrati senza premio finché non viene definita una nuova soglia. Nessun credito inter-app.
* Trasferimenti positivi interi, saldo sufficiente, niente auto-invio, chiave idempotenza per retry. Sblocco crediti per singolo fiore e modalità per 24 ore. Gli annunci premiano esclusivamente lo sblocco, non generano crediti trasferibili.
* Nessun diritto Premium acquistato viene modificato. I crediti preesistenti locali non possono essere accreditati ciecamente sul server, poiché sono modificabili dal dispositivo. Prima del rollout va definita e testata la migrazione: mantenere il saldo storico come credito locale spendibile e non trasferibile, senza perdita di acquisti, oppure una procedura verificata di migrazione.
* Lo script SQL è un candidato da verificare su database di prova, con test di concorrenza, RLS, cancellazione account, email effettive e audit di sicurezza. Non è stato applicato a un database live. Non abilitare i pulsanti invio/invito né pubblicare la release finché login, API, privacy, crediti e prove end-to-end non funzionano.

The native-only wallet client and all 16 wallet locale packs are included. Set PETALI_SUPABASE_URL and PETALI_SUPABASE_PUBLISHABLE_KEY for a dedicated Petali project in the build environment. The default configuration deliberately disables online wallet controls. Configure the OTP email template using {{ .Token }}, production SMTP, anti-abuse protections and email rate limits, test both account creation and deletion, then verify migrations and purchases before release. The existing offline wallet remains separate and never becomes transferable merely because the user logs in.
